# 美股半导体恐慌贪婪指数

参照 [CNN Fear & Greed Index](https://www.cnn.com/markets/fear-and-greed) 的编制思路，针对美股半导体板块计算 0–100 的情绪指数。

## 运行

```bash
uv venv .venv --python 3.12 && uv pip install --python .venv/bin/python -r requirements.txt
.venv/bin/python semi_fgi.py
open output/semi_fgi.html
```

可选参数：`--no-options` 跳过期权快照（沿用最近一次），`--no-cnn` 不抓取 CNN 指数。

## 网站

网址：https://1935zz.github.io/semi-fear-greed/

GitHub Actions（`.github/workflows/update.yml`）在美东交易时间每 5 分钟触发一次 `ci.py`：

- 盘中：重新计算并发布网页。GitHub 的定时任务常有延迟，实际约 5–15 分钟刷新一次。
- 收盘 15 分钟后：发布当天收盘版，抓取期权快照，并把当天数据提交到 `data/`。
- 盘前、休市、周末：跳过，网站保持最近一次内容。

网页打开后每分钟检查一次新数据，有更新会自动刷新。要手动更新，在仓库的 Actions 页面选"更新指数"，点 Run workflow。

## 输出

| 文件 | 内容 |
|---|---|
| `output/semi_fgi.html` | 仪表盘：仪表、历史读数、CNN 对照、走势图、8 个分项、分区回测、期权快照 |
| `output/semi_fgi.json` | 仪表盘使用的全部数据（网页每分钟拉取的就是它） |
| `output/semi_fgi_history.csv` | 每日综合指数、各分项得分和原始值 |
| `data/semi_fgi_history.csv` | 最近一次收盘版的历史，由定时任务提交 |
| `data/putcall_log.csv` | 每个交易日收盘后的期权 put/call 快照 |
| `cache/prices.pkl` | 当天的行情缓存。每天第一次运行全量下载，之后只下载最近 10 天 |

## 分项

| 分项 | 半导体指标 | 对应 CNN 分项 | 方向 |
|---|---|---|---|
| 板块动能 | SOX 相对 125 日均线 | Market Momentum | 越高越贪婪 |
| 股价强度 | 54 只成分股中接近 52 周新高家数减接近新低家数（3% 以内），占比 | Stock Price Strength | 越高越贪婪 |
| 股价广度 | 上涨股成交量减下跌股成交量，占总成交量，10 日均值 | Stock Price Breadth | 越高越贪婪 |
| 期权情绪 | VIX / VIX3M 期限结构 | Put/Call Options | 越高越恐慌 |
| 波动率 | VXN 相对 50 日均线（盘中缺数时按 VIX 涨跌推算） | Market Volatility | 越高越恐慌 |
| 避险需求 | SOX − TLT 20 日涨幅差 | Safe Haven Demand | 越高越贪婪 |
| 垃圾债需求 | log(HYG/IEF) 相对 50 日均值 | Junk Bond Demand | 越高越贪婪 |
| 杠杆资金 | 每日 log(SOXL 成交额 / SOXS 成交额) 的 10 日均值 | 半导体特有 | 越高越贪婪 |

每个分项用过去 504 个交易日（约两年）的均值和标准差算 z 值，经正态分布函数映射到 0–100；综合指数为等权平均（至少 6 项有值）。分档沿用 CNN：0–24 极度恐慌，25–44 恐慌，45–55 中性，56–75 贪婪，76–100 极度贪婪。

Put/Call 没有直接计入：Yahoo 只提供当前期权链，没有历史，而行业 ETF 的 P/C 比常年因机构对冲偏高，单日数值无法标准化。脚本每次运行都会记录快照，积累约一年后可以加为分项。

## v2 改动（2026-10-21）

v1 的 8 个分项里有 5 个本质上都在衡量 SOX 近期涨跌（动能与强度相关系数 0.91，相对强度、避险需求与 SOX 20 日涨幅相关 0.84–0.90），而且一年窗口下动能、强度、杠杆资金有 22–26% 的天数顶格，读数改善时分数几乎不动。v2：

- 去掉与避险需求重复的"相对强度"（SOX − SPY），新增不依赖价格的 VIX 期限结构。
- 股价强度改用 CNN 的新高减新低家数，股价广度改用成交量广度，成分股从 30 只扩到 54 只。
- 杠杆资金改成先算每日比值再平均，盘中当天成交量不完整时不再被稀释。
- 标准化窗口从 252 日改为 504 日。

在 2021-07 以来的样本上：与 CNN 指数的相关系数从 0.51 升到 0.76，读数日变化幅度基本不变（6.5 → 6.7），分项顶格比例从 17.5% 降到 11.6%。也测试过线性映射和"先平均 z 值再映射"，前者让综合指数几乎到不了两端，后者有 1/4 的天数顶格，都没有采用。

## 已知局限

- 成分股名单是固定的，用的是今天的成分，回看历史时有幸存者偏差。
- 期权情绪和波动率用的是标普和纳指的波动率，不是半导体专属的。
- 盘中运行时最后一行是未收盘数据。
- CNN 的数据接口是网页内部接口，可能随时变更；失败时仪表盘会隐藏对照部分，指数本身不受影响。
